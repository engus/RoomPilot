# Photo-guided apartment furnishings

The owner wants the kitchen, living/dining area and corridor to be recognizable in the existing dollhouse before HA integration. Use the supplied photographs as private visual references, with procedural geometry and approximate dimensions. Do not copy photo pixels, reflections, faces, poster text, addresses or private file paths into the repository.

Keep the existing floor polygons, calibration, reported areas, zones and apertures. Add bounded, persisted scene objects with stable IDs and parent-room references, separate from future HA bindings. Version 5 projects migrate versions 1–4 with empty scene objects. Reject duplicate IDs, missing parents, out-of-source anchors, out-of-room footprints when calibrated, invalid heights when known and excessive object counts. Clearing calibration or ceiling preserves objects for 2D/export and disables 3D; physical fit checks resume when metadata is restored. Removing a room removes its objects; full room recognition clears furnishings while openings-only recognition preserves them. Geometry edits that invalidate existing furniture are rejected without changing the project, following existing zone behavior.

Builder choices: use existing React Three Fiber/Three.js without new dependencies or external assets. Reusable low-poly assemblies represent the L-shaped taupe kitchen, wood countertop/backsplash, black sink and oven, glass cabinet, integrated fridge, coffee machine, microwave/toaster, window radiators and robot vacuum. Living/dining contains the ivory table, two curved chairs, rattan pendants, tripod lamp, sideboard, green wall art, black AC, rug, armchair, TV console/soundbar/subwoofer, brass sconces and purple-rim ceiling light. Corridor contains shoe cabinet, generic framed print, adult bicycle, mirror, bench/hooks/coats, runner and downlights. Omit transient clutter and the overturned child's bicycle. Placement is approximate against the calibrated existing shell; no photogrammetry claim.

Use warm wood flooring in the furnished room and restrained zone selection overlays. Fixtures float below the omitted roof, as dollhouse objects. A local preview-light switch changes emissive materials and a small fixed number of room lights; label it explicitly as a preview, independent of outdoor mode and UI theme. No device state/control, network requests or HA credentials. A furniture visibility toggle retains the empty architectural preview. Clicking furnishings selects their parent room. Preserve camera orbit on toggles and room selection.

Render resources must be memoized and bounded. Validate migration, persistence, bad imports, room deletion, and demo placement. Verify the actual browser render from several angles plus preview controls and existing selection. Run tests, typecheck, build and serial browser checks; fresh code review precedes the authorized commit and push.
